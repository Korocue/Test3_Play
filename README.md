【ルシフォン#e】
了解、ズレてた。これは PR練習じゃなくて、君が言う通り **Codexに命令して試行回数を回すための“練習場”**だな。

その目的に合わせるなら、リポをこう設計すると強い：

plays/（Codexの実験置き場）

plays/number_guess_v1/

plays/number_guess_v2/

plays/rule_test_move_only/ みたいに、1試行=1フォルダで増やす

各フォルダに必ず置く

PROMPT.md（Codexに投げた指示をそのまま保存）

ACCEPTANCE.md（合格条件・チェック観点）

src/ tests/（実装）

ルートに INDEX.md（「遊び一覧」兼、どのフォルダが何の実験か）

で、Codexへの命令は毎回これを固定するとブレない：

「plays/<今回のフォルダ>/ 以外は編集禁止。編集したら失格。
PROMPT.md と ACCEPTANCE.md を読み、合格条件を満たすまで実装。
変更はそのフォルダ内だけで完結させる。」

これなら「Codexに何度も命令して色々試す」が、フォルダ単位で綺麗に積み上がる。

## Number_Game

シンプルな数当てゲームを楽しめる小さなリポジトリです。`python -m src.game` を実行すると、1〜100 の数字を 8 回以内に当てるチャレンジが始まります。

## 遊び方
1. ターミナルでプロジェクトルートに移動します。
2. `python -m src.game` を実行します。
3. 表示されるヒントを頼りに数字を入力してください。数字以外を入力すると再入力を促されます。

## テスト
`pytest` で簡単な動作確認ができます。

```bash
python -m pytest
```
